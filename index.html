infoPanduan Deploy ke GitHub Pages

  1. Upload file index.html ke repositori GitHub
  2. Buka Settings → Pages → Source: Deploy from branch → main → / (root)
  3. Tunggu beberapa menit, site akan live di https://[username].github.io/[repo]
  4. Isi Spreadsheet ID dan GID dari URL spreadsheet Google Sheets Anda
  5. Deploy Code.gs sebagai Web App → isi URL-nya di pengaturan ini
  6. Pastikan spreadsheet diset "Anyone with the link → Viewer"
